# HARISH R — IT Professional & Data Analyst Portfolio

An editorial, high-performance portfolio website inspired by the design language of [Vertical Framer](https://vertical.framer.media/). Engineered with React 19, Vite, Tailwind CSS v4, Motion (Framer Motion), and TypeScript.

---

## ✦ Key Features

- **Vertical Framer Editorial Aesthetic**:
  - Dark obsidian theme (`#09090b`) with hairline architectural grid lines and structured editorial typography.
  - High-contrast typography pairing: Syne & Space Grotesk display headers, IBM Plex Mono metadata badges, and Inter prose.
  - Live Indian Standard Time (IST) clock with live status beacons (`Open to Work`, `Vellore, IN`).
  - Floating dynamic dock navigation with active scroll tracking.

- **Interactive Machine Learning & Vision Simulators**:
  - **MOD — 01: Driver Distraction Prediction**: Live simulated camera telemetry with bounding box classification, gaze pitch calculation, and real-time hazard status.
  - **MOD — 02: Heart Disease Clinical Risk Calculator**: Interactive patient parameter sliders (Age, BP, Cholesterol, Max HR, Chest Pain) with real-time ML risk scoring and algorithm comparison (Random Forest, SVM, Logistic Regression).

- **Structured Content Matrix**:
  - **Professional Summary & Manifesto**: Clear positioning as an MCA candidate and entry-level IT / Data Analyst professional.
  - **Technical Capabilities Grid**: 4 disciplined pillars covering Programming (Python, C, C++), Data & ML, Web Technologies (HTML5, CSS3), and SQL.
  - **Education Chronology**: MCA (2025–2027 Pursuing), BCA (2022–2025), HSC, and SSLC.
  - **Certifications & Credentials**: Java Foundations & Big Data Analytics (Great Learning Academy).
  - **Strengths & Languages**: Core professional strengths and multilingual fluency (Tamil, English).
  - **Interactive Contact & Dispatch**: One-click copy for Email and Phone, LinkedIn connection link, and an interactive message form.
  - **Printable Curriculum Vitae Modal**: In-browser resume viewer with one-click print/PDF save and text copy.

## ✦ Running Locally

1. **Install dependencies** (if not already installed):
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   # or
   npm run dev:vite
   ```

3. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) (or the URL printed by Vite).

---

## ✦ Build for Production

```bash
npm run build
```
The optimized static build will be generated in `dist/`.
